# Toegankelijkheid

De Nederlandse Digitale Dienst wil dat iedereen deze website kan gebruiken. In het register van toegankelijkheidsverklaringen heeft de NeRDS **status D: voldoet niet**. De verklaring is van 27 oktober 2025.

Lees de [toegankelijkheidsverklaring van de NeRDS](https://www.toegankelijkheidsverklaring.nl/register/28093) voor wat er is onderzocht en wat er nog niet voldoet.

Loop je op deze website ergens tegenaan? Laat het weten via [Contact en bijdragen](CONTRIBUTING.md).
