# NeRDS Richtlijn 2: Zorg voor toegankelijkheid en inclusie

Lees [richtlijn.md](richtlijn.md) voor bewezen praktijken en hulpmiddelen, en [fases.md](fases.md) voor implementatie per fase.

Gerelateerde richtlijnen: `/nerds-gebruikers`, `/nerds-standaarden`

Bouw je de interface met het NLDD Designsysteem, gebruik dan de skills uit de plugin `nldd-design-system`. Is die plugin niet geïnstalleerd, geef de gebruiker dan deze twee opdrachten:

```text
/plugin marketplace add NederlandseDigitaleDienst/ai-plugins
/plugin install nldd-design-system@nldd
```

Dat zijn de opdrachten voor Claude Code. Voor Cursor en voor de overstap vanaf de oude naam `nldd@nldd-plugins` staat de uitleg in de [marketplace van de Nederlandse Digitale Dienst](https://github.com/NederlandseDigitaleDienst/ai-plugins#installeren).
